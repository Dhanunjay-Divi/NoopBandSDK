# Decisions

| ID | Decision | Status |
|---|---|---|
| SDK-D-001 | The band SDK is a separate private repository and release artifact from the NOOP application repository. | Superseded by SDK-D-010 on 2026-09-23 |
| SDK-D-002 | Public SDK APIs, source, tests, samples, and documentation are English-only. Original vendor drops remain immutable and untracked rather than rewritten. | Active |
| SDK-D-003 | One phone is the active collector; Mac and other devices are managed-sync viewers. | Active |
| SDK-D-004 | Supplier binaries remain outside Git and outside application builds until rights, SBOM, security, egress, exact-model, and physical gates pass. | Active |
| SDK-D-005 | Supplier types and persistence remain behind neutral Apple/Android adapters; NOOP owns provenance, storage, checkpoints, diagnostics, and product behavior. | Active |
| SDK-D-006 | No GitHub Actions workflow is enabled initially. Local deterministic checks precede one budgeted hosted release check when approved. | Active |
| SDK-D-007 | Cross-platform bounded strings use UTF-8 bytes; samples use non-negative signed 64-bit sequence/time domains; recent identity memory is bounded and application storage remains the durable dedupe authority. Restart-safe duplicate suppression requires one canonical SHA-256 payload fingerprint per recent identity, with signed zero normalized. The digest is sensitive integrity metadata, not encryption, and must remain in encrypted app storage outside logs and exports. Legacy identity-only checkpoints retain cursor progress but do not suppress replay without payload evidence. | Active |
| SDK-D-008 | Reconnect interruption and completion require exact session-issued connection and reconnect credentials; a disconnected non-firmware operation returns resume authority, while invalidated connection/capability/firmware recovery requires rediscovery. Kotlin snapshots supplier-owned collections with bounded traversal and rejects JVM null elements as fixed invalid input. | Active |
| SDK-D-009 | Capability schema 3 binds every advertised lane and stream to one immutable unit, cadence, quality, timestamp, parser, calibration, and report-revision contract. It also declares the exact operation classes allowed during live collection. Accepted live/history data carries that provenance, and bounded staged evidence is recorded before application persistence begins. | Active |
| SDK-D-010 | The NOOP-owned, source-only band SDK remains in the separate public `Dhanunjay-Divi/NoopBandSDK` repository by owner decision. Supplier binaries, firmware, credentials, signing material, private reference inputs, device identifiers, and user or health data remain excluded. The application consumes only an exact revision and digest-pinned export; hosted SDK Actions remain disabled until separately approved. | Active |
